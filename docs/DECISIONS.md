# 决定记录

记录做过的取舍和原因，免得以后重新争论。新的写在最上面。要改某个决定，就新加一条说明为什么改，不要删旧的。

## 2026-11-05 UMA 设备选项：自动、NVIDIA、AMD、Apple、CPU

fairchem 2.25（目前最新）只接受 `cuda` 和 `cpu`（`assert device in ["cpu", "cuda"]`）。AMD 显卡在 ROCm 版 PyTorch 里就是 `cuda`，所以能用；Apple GPU（MPS）fairchem 不支持，选 Apple 时在 M 系列 CPU 上跑，页面写明。默认“自动检测”：有 GPU 用 GPU，否则 CPU。桌面版的参数检查同步放宽到这五个值。
**原因：** 用户要求加上 Apple 和 AMD 的选项；不能假装 Apple GPU 可用。

## 2026-11-05 训练页的模型每周四自动核对；网状图改成持续运行的力导向

`tools/train-models.mjs` 跟目录刷新一起跑：读出训练页上所有 Hugging Face 模型链接，查是否还在、近 30 天下载、点赞、更新日期；再从各家实验室的官方账号找出近 60 天新发布、40B 以下、上表没有的文本或图文模型（排除量化版、草稿头、Base 等），写进 `public/train/models-live.js`。手写的模型介绍不自动改；新模型只列出，标明未经人工评测。Hugging Face 出问题时保留上周的文件。
网状图不再“排好就定住”：所有力共用一个下限，图在静止时保持形状、轻微漂动，拖动时邻居弹性跟随；悬停淡出无关节点、沿连线流动光点；换中心时镜头滑过去，旧节点淡出，新节点从它挂靠的节点里长出来。尊重“减少动态效果”设置。
**原因：** 用户要求模型模块每周更新、网状查询要有 Obsidian 那样的灵动感。

## 2026-11-05 网状查询重做：以查询为中心的实体网，节点由数据现算

旧版只有约 250 个节点（来源、前 24 个标签、分类、目录官网），只在博客和论坛里出现的程序（如 Shermo）进不了图，搜索只是给已有节点描金边。新版在浏览器里用 `hub/net-engine.js` 从全部条目、19 章讲解手册和 `search-terms.js` 算出约 430 个实体：目录里的软件与数据库、标题里至少出现两次的拉丁名（排除站长随笔、期刊缩写和普通英文词）、术语表的每一组概念、主题标签、资源分类。关系是同一条目里共同出现，标题和标签算 3、摘要和正文算 1，按余弦归一化；宽泛词打折，同一事物的不同写法（DFT / 密度泛函）不算关系；同一篇文章的博客原文和论坛镜像合并成一条。查询依次试精确名、别名、同义词、前缀补全和拼写近似，都不中才做全文检索。
**原因：** 用户要求“搜 Shermo 就让 Shermo 和它关联的东西出现在中心”，并且数据每周更新，所以关系必须现算，不能手工维护。不用图形库，保持全站无构建、可离线。

## 2026-11-05 讲解手册改名“说明讲解手册”，正文中英双语

英文版放在 `atlas/guides-en.js`（DeepSeek 起草、逐章核对，结构与中文版逐标签一致），阅读器里可切换；默认跟随全站语言，读者选过的语言按全站语言分别记住。英文版章节标题下的小字换成中文原标题。正文仍是原材料的内容（103 条资源时期），没有为新增的量子类别补写章节。
**原因：** 以前英文访客只能看到一句“请用浏览器翻译”；讲解正文是最有价值的部分，应该原生提供英文。

## 2026-11-05 目录每周四自动刷新，抓不到就沿用上周

`refresh-data.yml` 在 GitHub Actions 上运行原来的 Python 爬虫和 `hub-chemrxiv.ts`，提交后用 `gh workflow run pages.yml` 触发发布（用 GITHUB_TOKEN 推送不会自动触发其他工作流）。某个来源失败时爬虫沿用上周条目；`check-catalogue.mjs` 在条目减少超过 15% 或有来源为空时拒绝提交。
**原因：** 爬虫在海外的 CI 机器上也能跑通公开来源；宁可旧一点，也不能让一次失败的抓取清空目录。

## 2026-11-05 其他服务商放在“其他兼容接口”里，不写进页面介绍

AI 设置的服务商卡片仍是 DeepSeek、Meta Muse、其他兼容接口三张；19 家服务商作为“其他兼容接口”的预设，填好 key 后从各家的 `/models` 读取模型列表，不写死型号。只收 CORS 预检通过的（2026-11-05 测过；智谱、腾讯混元、NVIDIA 不允许浏览器直接调用，没收）。Anthropic 需要 `anthropic-dangerous-direct-browser-access` 头。新模型拒绝 `max_tokens` 或 `temperature` 时自动按报错改参数重试一次。
**原因：** 用户要求能接各家 API，但页面介绍保持 Meta / DeepSeek 的定位；型号变化快，写死很快就过时。

## 2026-11-05 桌面版跑 UMA：脚本编译进应用，页面只传参数

桌面版的“在本机运行”用访客自己的 Python（自动找 `py -0p`、PATH、python.org 和 conda 的安装位置，也可以填路径）。要跑的 Python 脚本 `uma/runner.py` 用 `include_str!` 编进应用，页面只能传 SMILES、任务、模型、设备、电荷、自旋，Rust 端逐项校验；解释器必须是叫 python / python3 的绝对路径。日志用轮询取（和更新进度一样），没有引入前端 Tauri 包。计算结果写在应用数据的 `uma-runs/` 下，IP/EA 通过 localStorage 交给 AI 实验室导入。
**原因：** 这个页面会显示 AI 和外部接口返回的内容，一旦出现注入，能执行任意代码的接口就等于把访客的电脑交出去；只传参数时最坏也只是算错一个分子。环境不全时只给出可复制的安装命令，不替访客装包、不碰 Hugging Face token。

## 2026-11-05 Meta 页：识图只用访客自己的 Muse key，UMA 只生成脚本

识图把图片发给 `api.meta.ai`（Muse Spark 1.3 能看图），只认访客在 AI 设置里填的 Muse key，不走 Pro 托管额度：账号服务按文字计次，图片很大，也没测过它转发图片。UMA 需要 PyTorch 和 GPU，网页里跑不了，所以生成 fairchem 脚本让用户在自己的机器上算；IP / EA 的定义和列名与 AI 实验室一致，UMA-M 在 UMA-S 几何上算单点。数据集只链接论文和官方页面，不复制数据。
**原因：** 不替访客付图片的钱，也不让图片经过本站；脚本比“云端 UMA”诚实，访客拿到的是能复现的完整计算。导航标签用短的“Meta”，长标签会让中文导航在 1280–1366 px 宽时折成两行；同时去掉了预印本雷达的“新”标记。

## 2026-11-03 量子化学计算用 iframe 内嵌，只有深色，自带中英文

`tools/vendor-qchem.ts` 把 qchem-web 构建好的单文件复制到 `public/qchem/app/`。外层页面传 `?embed=1&lang=en|zh`：它用自己的词典翻译，隐藏自己的语言按钮，不加载站点的 `i18n.js`，也不跟站点的浅色/深色开关。和预印本雷达一样不放进 `bundle-single`。
**原因：** 它是独立仓库，单独发布在 GitHub Pages 上也要能切换中英文；图表都画在 canvas 上，配色按深色调过，做浅色版要重画所有图。两套词典各管各的，互不影响。

## 2026-10-31 每周精选跑在 Worker 免费版上：小批量发送，每天最多 80 封

周一 12:00–20:00（UTC）每小时试一次生成，成功后不再生成；每 15 分钟发 5 封，每天最多 80 封，给验证码邮件留出 Resend 的额度。只发当周这一期。标题公开（Pro 页预览），解读和邮件给 Pro。解读由 `deepseek-flash` 根据标题和摘要写；模型失败或选出不足 3 篇时，改发不带解读的论文列表。
**原因：** Workers 免费版每次调用的 CPU 时间很短，Resend 免费版每天 100 封，这样不用升级就能运行。订阅者超过每周能发完的量时再升级 Resend。

## 2026-10-31 退订链接打开后要再点一次按钮，邮件客户端的一键退订例外

GET 只显示确认页，POST 才退订；邮件头的 `List-Unsubscribe-Post` 走 POST。
**原因：** 邮件安全扫描器会自动打开邮件里的链接，GET 就退订会把人误退掉。

## 2026-10-31 搜索同义词用手写的术语表

`public/search-terms.js` 列出中英对照的术语组，短拉丁词按整词匹配。不用向量检索，也不让 AI 改写搜索词。
**原因：** 网站是静态的，搜索在访客浏览器里运行，要免费、即时、结果说得清为什么命中。术语太宽会带来很多无关结果，所以 potential、position、cluster 这类词已收窄；后续按没有结果的搜索词补充。

## 2026-10-31 托管 AI 按可能的花费多计次数，不做 token 记账

一次问答计 1 次（输入不超过 12,000 字、输出上限不超过 4,096 token）。超出按比例多计，`deepseek-v4-pro` 再乘 3（`HOSTED_MODEL_WEIGHTS`）；一次最多 48,000 字，只接受文字。短调用要同时满足输出不超过 400 token、输入不超过 2,000 字，否则按正式问答计。同一账号最多 5 台设备同时登录。
**原因：** 原来只按次数算，一个账号可以用长内容和贵模型花掉远超订阅费的钱，也能多人共用。流式回答里读 token 用量要改动较多，而且只有事后才知道；按请求大小预先计次简单，还能在发送前拒绝。网站发送长对话时会裁掉旧消息，普通用户每次仍只计 1 次。

## 2026-10-31 项目知识放进仓库，不靠聊天记录

`CLAUDE.md` 和 `docs/` 是公开的，放项目规则和背景；私人事项放本机 Claude 记忆。仓库的 `.claude/settings.json` 把记忆目录指向 `~/.claude/projects/D--ChemDraw/memory`，这样从 `D:\ChemDraw` 和从仓库目录开的会话看到的是同一份记忆。

## 2026-10-29 VIP 卡的有效期每次从 `cards` 表计算

## 2026-10-29 账号服务不用 webhook，直接向 Stripe 查询

用只读受限密钥（Customers、Checkout Sessions、Subscriptions）查询，结果在 D1 缓存 6 小时。
**原因：** 少一个公开入口和签名密钥，谁付过钱永远以 Stripe 为准，漏事件也不会错。代价是退款或取消最多 6 小时后才反映。

## 2026-10-29 没有密码，用邮箱验证码登录

验证码接口对任何邮箱都回答 ok。
**原因：** 不用保管密码；回答一致，别人查不出谁买过。

## 2026-10-29 账号服务放在 Cloudflare Worker + D1，域名 DNS 搬到 Cloudflare

**原因：** 免费额度够用，不用维护服务器；`workers.dev` 在中国大陆通常打不开，所以用 `api.molastria.com`，这要求 DNS 在 Cloudflare。

## 2026-10-29 托管额度：每席每月 300 次，短调用单独计数，失败退回

`max_tokens ≤ 400` 的调用（关键词提取、连接测试）算短调用，额度是正式问答的 2 倍。
