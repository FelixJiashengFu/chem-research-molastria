# 决定记录

记录做过的取舍和原因，免得以后重新争论。新的写在最上面。要改某个决定，就新加一条说明为什么改，不要删旧的。

## 2026-10-31 项目知识放进仓库，不靠聊天记录

`CLAUDE.md` 和 `docs/` 是公开的，放项目规则和背景；私人事项放本机 Claude 记忆。仓库的 `.claude/settings.json` 把记忆目录指向 `~/.claude/projects/D--ChemDraw/memory`，这样从 `D:\ChemDraw` 和从仓库目录开的会话看到的是同一份记忆。
**原因：** 项目要维护很多年，不能依赖某一段聊天。测试脚本和 wrangler 原来放在会话的临时目录，也一并搬进了仓库。

## 2026-10-29 VIP 卡的有效期每次从 `cards` 表计算

不在 `grants` 里累计天数，而是把一个邮箱兑换过、没被收回的卡按兑换顺序首尾相接。
**原因：** 累计的话，收回其中一张卡时分不清该扣多少天；这样收回哪张就正好少哪张。

## 2026-10-29 站长身份只能用命令写入数据库

`grants` 表没有任何写入接口，只能用 `wrangler d1 execute` 写。
**原因：** 这是权限最高的身份，不留从网站上提权的可能。

## 2026-10-29 预印本雷达用 iframe 内嵌，保留书香风格

`tools/vendor-radar.ts` 复制 PreprintRadar 的构建结果到 `public/radar/app/`，复制时把深色规则改成同时认站点的主题开关。
**原因：** 它是独立项目，有自己的布局和全局样式；内嵌能完全隔离，也不用改它的仓库。

## 2026-10-29 ChemRxiv 用 Crossref，按关键词筛计算化学

**原因：** ChemRxiv 2026 年搬到 Wiley，官网对程序返回 Cloudflare 验证，不应绕过；Crossref 几分钟内就有新稿且带摘要，但没有学科字段。

## 2026-10-29 托管 AI 只开放 DeepSeek，不开放 Muse

**原因：** 用满 300 次时，Muse Wonder 约 US$24/月，Spark 约 US$6/月，都超过 Pro 月费 ¥29（约 US$4.35）。

## 2026-10-29 账号服务不用 webhook，直接向 Stripe 查询

用只读受限密钥（Customers、Checkout Sessions、Subscriptions）查询，结果在 D1 缓存 6 小时。
**原因：** 少一个公开入口和签名密钥，谁付过钱永远以 Stripe 为准，漏事件也不会错。代价是退款或取消最多 6 小时后才反映。

## 2026-10-29 没有密码，用邮箱验证码登录

验证码接口对任何邮箱都回答 ok。
**原因：** 不用保管密码；回答一致，别人查不出谁买过。

## 2026-10-29 账号服务放在 Cloudflare Worker + D1，域名 DNS 搬到 Cloudflare

**原因：** 免费额度够用，不用维护服务器；`workers.dev` 在中国大陆通常打不开，所以用 `api.molastria.com`，这要求 DNS 在 Cloudflare。

## 2026-10-29 托管额度：每席每月 300 次，短调用单独计数，失败退回

`max_tokens ≤ 400` 的调用（关键词提取、连接测试）算短调用，额度是正式问答的 2 倍。

## 2026-10-28 用人民币收款，Pro 和课题组版自动续费

Pro ¥199/年或 ¥29/月；课题组版 ¥298/席/年，最少 5 席。英文页显示人民币价加美元约数。
付款走 Stripe 托管结账页，网站不接触卡号。

## 2026-10-28 桌面版用 Tauri，版本号来自标签，暂不做代码签名

更新文件用自己的密钥签名，放在 GitHub Releases。
**原因：** 体积小（约 3 MB）；代码签名要花钱，等有需要再做，下载页已说明首次打开的提示。

## 2026-10-28 中文是源语言，英文运行时翻译

界面直接写中文，`i18n.js` 按文本匹配替换；译文由 DeepSeek 补全，手改的不会被覆盖。论文标题、论坛帖、讲解正文保留原文。
