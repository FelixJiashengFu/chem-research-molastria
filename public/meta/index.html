TOOL 01 · MUSE SPARK VISION

Muse 识图：从一张图得到可计算的结构

把文献截图、ChemDraw 截图或手绘结构交给 Muse Spark，它给出名称和 SMILES；浏览器里的 RDKit 再逐个校验，画出结构、算出分子式。校验不过的会标出来，不会悄悄当成正确答案。

识图用你自己的 Meta Model API key（在右上角「AI 助手」→ 设置里填），图片直接发给 Meta，本站不保存。

识别结果会显示在这里。

TOOL 02 · UMA ON YOUR OWN GPU

UMA 脚本生成器：在自己的电脑上跑 Meta 的原子模型

UMA 需要 PyTorch 和 GPU，不能在网页里运行。这里按你的分子和计算目的生成一份完整的 fairchem + ASE 脚本：RDKit 生成三维结构，UMA 优化和计算，结果写成文件。IP / EA 的输出可以直接导入 AI 实验室。

  1. 安装：pip install fairchem-core rdkit
  2. 申请模型访问： huggingface.co/facebook/UMA，通过后运行 huggingface-cli login
  3. 在单独的环境里安装：pip install mace-torch rdkit（mace-torch 固定 e3nn 0.4.4，和 fairchem 装在一起会冲突）
  4. 第一次运行会从 GitHub 下载 MACE-OFF23 模型，不用申请。它采用学术软件许可（ASL），仅限非商业用途。
  5. 运行：python uma_FEC_ipea.py
uma_FEC_ipea.py

在线运行：用站长的 GPU 免费算

不用装任何东西：把上面的分子交给站长电脑上的模型计算。每个模型一次只给一个人算，其余按提交顺序排队；每人同时只能有一个任务；算过的分子直接给结果。Meta 的 UMA 和 OMol25 模型、MACE 系列对所有人免费，ANI-2x 是 Pro 会员的模型。UMA-M 1.1 的权重有 11 GB，站长电脑的内存和显存装不下，暂不提供。

一个模型覆盖分子、材料、催化、MOF 和分子晶体，用任务头切换。UMA-S 1.2.1 激活 660 万、总计 2.9 亿参数；UMA-M 1.1 激活 5000 万、总计 14 亿参数。
许可：FAIR Chemistry License，需在 Hugging Face 申请

数据集2025本站在用
OMol25 · Open Molecules 2025
超过 1 亿次 ωB97M-V/def2-TZVPD 计算，83 种元素，约 8300 万个分子体系，最大 350 个原子；包含显式溶剂、不同电荷与自旋、构象和反应结构。
许可：CC BY 4.0
论文

      
数据集2024
OMat24 · Open Materials 2024
超过 1.1 亿次无机材料 DFT 计算，强调结构和组成的多样性。与 Materials Project 的能量设置不兼容，比较形成能时要注意。
许可：CC BY 4.0
论文Hugging Face

      
数据集2025
OMC25 · Open Molecular Crystals 2025
超过 2700 万个分子晶体结构，12 种元素，每个晶胞最多 300 个原子，来自 23 万多个结构的含色散校正 DFT 弛豫轨迹。
许可：CC BY 4.0
论文Hugging Face

超过 657 万次聚合物团簇 DFT 计算，合计 12 亿多个原子，覆盖单体组成、聚合度、链结构和溶剂环境的变化。
