方法、边界与刷新方式

只搬标题，不搬全文

每条只保留标题、≤180 字短摘要与原文链接，并标注来源。阅读全文请点「原文」回到原站——流量与版权都归原作者。

不绕过人机验证

计算化学公社（阿里云 WAF）与 X-MOL 深层页会触发真人验证，本站不做任何绕过。公社内容改用 Sobereva 官方博文目录中公开的交叉引用（真实帖标题 + 真实 thread 链接），并打「目录镜像」标签；X-MOL 用同日抓取的真实首页快照解析学科频道。

尊重 robots 与频率

同站请求间隔 ≥1.1 秒；不抓各站 robots 禁止的搜索/订阅路径；X-MOL 每次刷新只请求一次首页。某站失败时保留上次缓存，绝不用空数据冒充。

新来源同样守规矩

arXiv、Crossref、GitHub 走官方 API；官方软件目录逐站抓首页标题与 meta 描述，抓不到就跳过。小木虫论坛帖被其 robots.txt 明确禁止抓取，故不收录；ChemRxiv、Materials Project 被 Cloudflare 拦截，同样不绕过、仅在 README 中说明。

如何更新这份快照

浏览本包无需安装依赖。需要重新采集时，在包根目录的 maintenance 内创建 Python 虚拟环境，安装 requirements.txt，再运行 refresh_data.py。它会更新社区数据、离线数据脚本及统一搜索索引；具体命令见包内 README.md。
