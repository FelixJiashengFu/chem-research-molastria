      Lipinski 五规则：分子量 ≤ 500、cLogP ≤ 5、氢键供体 ≤ 5、受体 ≤ 10，最多违反一条算通过（Lipinski 2001）；Veber 规则：可旋转键 ≤ 10 且 TPSA ≤ 140 Å²（Veber 2002）。两条都是口服药的经验规则，不适用于天然产物、抗生素和许多新药类型。
      
    
      
    
      
      
      按结构搜 PubChem
      
      
      画一个结构或写一个 SMILES，在 PubChem 的一亿多个化合物里找相似的、含有这个子结构的，或者就是它本身。浏览器直接问 PubChem，不经过本站；本站只把结果整理成表，再用 RDKit 算一遍相似度。
      
      
      
        
        
        
        
      
      
      
      
      
      还没有搜索。
      
      
      “相似结构”按 PubChem 自己的 881 位二维指纹（PubChem fingerprint）的 Tanimoto 筛选，PubChem 不返回具体分数；表里的“Morgan 相似度”是 RDKit 在你的浏览器里用 Morgan 指纹（半径 2，2048 位）重算的，表格按它从高到低排。两种指纹看的东西不一样，过了 PubChem 的下限、Morgan 值却不高是正常的。“含有这个子结构”最多列 20 个，PubChem 不保证是哪 20 个。

        研究一个开源项目时看什么
        
          
          
        1. 别只看 README：还要看核心实现、测试（数值有没有对照）、示例能不能跑，以及文档里的理论和参数说明。
          2. 
          
        2. 记下确切的版本：标签或提交哈希，最好再加 Zenodo DOI 或 Software Heritage 的 SWHID；不要只记一个会变的 main 分支链接。
          3. 
          
        3. 读一读 LICENSE 和 CITATION.cff：模型权重和数据集常有自己的许可证。
          4. 
          
        4. 从软件包反查源码：PyPI、conda-forge 的页面上都有“源代码”链接。
          5. 
          
        5. 从论文反查代码：论文的“代码可用性”一节、补充材料和作者主页。
          6.
