订阅（Pro、课题组版）

  • 14 天无理由退款：首次付款或续费后 14 天内申请，全额退还该笔款项。
  • 早鸟预售期间：如果你付款时标注“开发中”的功能尚未上线，你可以在任何时候申请退还当前周期未使用部分的费用。
  • 功能下线：若付费功能停止提供，按剩余期限比例退款。
  • 超过以上情形的，取消订阅后当前周期仍可使用，到期不再扣费，已付款项不予退还。

赞助

赞助是对开发的自愿支持，不对应具体服务。如果是误操作或金额填错，请在 14 天内联系我们，我们会全额退还。

怎么申请

  1. 回复 Stripe 发来的收据邮件，或通过 GitHub Issues 联系（不要在公开 Issue 里贴订单号以外的个人信息）。
  2. 写明付款邮箱与订单参考号。
  3. 我们会在 3 个工作日内处理，款项按原支付方式退回，到账时间取决于银行或支付平台。
