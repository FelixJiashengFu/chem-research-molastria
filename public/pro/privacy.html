隐私政策

生效日期：2026-10-28 · 更新：2026-10-31（新增每周精选）

我们不收集什么

MolAstria 网站是静态页面，免费功能不需要账号，不使用广告或跨站追踪。你的搜索、收藏、AI 实验室项目、界面偏好（语言、主题、背景）都只保存在你自己的浏览器（localStorage / sessionStorage）里，我们看不到。

AI 与 API key

你填写的 DeepSeek、Meta Muse 或其他服务的 API key 只保存在你的浏览器中，请求从你的浏览器直接发往你选择的服务商，适用该服务商的隐私政策。若站点启用了托管代理，对话内容会经过代理转发给服务商，代理不保存对话内容。

付款

付款在 Stripe 的托管结账页完成。Stripe 会收集完成付款所需的信息（邮箱、支付方式、账单国家等），并按其隐私政策处理。我们只会从 Stripe 后台看到你的邮箱、所购套餐、金额与付款状态，用于开通服务、发送上线通知和处理退款，不会出售或转让给第三方。

Pro 账号

购买 Pro 或课题组版后，账号服务（运行在 Cloudflare 上）会保存：你的付款邮箱；从 Stripe 查到的订阅状态（套餐、席位数、续费或到期时间）；登录会话（只保存不可逆的摘要）；每月 AI 托管额度的使用次数；课题组购买者添加的成员邮箱。登录验证码和课题组邀请通过 Resend 发送到你的邮箱。

订阅每周精选邮件时，账号服务会保存你的邮箱、语言和发送记录，邮件通过 Resend 发出；退订后删除这些记录。每封邮件都有退订链接。

使用 AI 托管额度时，对话内容经账号服务转发给 DeepSeek 等模型服务商并适用其隐私政策；账号服务只计次数，不保存对话内容。登录令牌只存在你的设备上，退出登录即在服务端作废。

托管与第三方资源

网站托管在 GitHub Pages，访问时 GitHub 可能按其政策记录访问日志。部分页面会从 cdn.jsdelivr.net 加载 RDKit.js，从 PubChem 查询分子信息；这些请求由你的浏览器直接发出。

你的权利

你可以随时清除浏览器数据来删除本地保存的内容；也可以联系我们查询、更正或删除我们因付款与 Pro 账号而持有的邮箱、订单与用量记录（法律要求保留的财务记录除外）。
