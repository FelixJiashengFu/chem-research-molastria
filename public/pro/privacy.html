隐私政策

我们不收集什么

MolAstria 网站是静态页面，免费功能不需要账号，不使用广告或跨站追踪。你的搜索、收藏、AI 实验室项目、界面偏好（语言、主题、背景）都只保存在你自己的浏览器（localStorage / sessionStorage）里，我们看不到；只有你登录后自己打开了云同步，学习记录和收藏才会存到你的账号里（见下面“云同步”）。另一个例外是网状查询里术语表认不出的词，见下面“网状查询里没找到的词”。

网状查询里没找到的词

在网状查询里搜一个术语表认不出的词，这个词会记在你浏览器里的“没找到的词”列表中。第一次记下某个词时，你的浏览器还会把这个词本身和全文检索命中的条数发给账号服务一次，用来统计全站哪些词最常搜不到，好补进术语表。不带登录令牌，也不带你的其他搜索；网址、邮箱、长串数字和太短或太长的输入不会发送。

账号服务只保存词、报过的次数、最近一次的命中条数和第一次、最近一次的时间，不保存 IP 地址、账号或来源页面，只有站长能看到汇总；汇总最多保留 3000 个词，补进术语表后会删掉。请求经过 Cloudflare 的网络，和访问网站一样适用 Cloudflare 的日志政策。在网状查询页取消“匿名报给站长”就不再发送；取消“记下术语表认不出的词”则既不记录也不发送。

AI 与 API key

你填写的 DeepSeek、Meta Muse 或其他服务的 API key 只保存在你的浏览器中，请求从你的浏览器直接发往你选择的服务商，适用该服务商的隐私政策。若站点启用了托管代理，对话内容会经过代理转发给服务商，代理不保存对话内容。

付款

付款在 Stripe 的托管结账页完成。Stripe 会收集完成付款所需的信息（邮箱、支付方式、账单国家等），并按其隐私政策处理。我们只会从 Stripe 后台看到你的邮箱、所购套餐、金额与付款状态，用于开通服务、发送上线通知和处理退款，不会出售或转让给第三方。

账号

用邮箱登录（免费账号）或购买 Pro、课题组版后，账号服务（运行在 Cloudflare 上）会保存：你的邮箱；从 Stripe 查到的订阅状态（套餐、席位数、续费或到期时间）；登录会话（只保存不可逆的摘要）；AI 托管额度和在线模型的使用次数；课题组购买者添加的成员邮箱。登录验证码和课题组邀请通过 Resend 发送到你的邮箱。

订阅每周精选邮件时，账号服务会保存你的邮箱、语言和发送记录，邮件通过 Resend 发出；退订后删除这些记录。每封邮件都有退订链接。

使用 AI 托管额度时，对话内容经账号服务转发给 DeepSeek 等模型服务商并适用其隐私政策；账号服务只计次数，不保存对话内容。登录令牌只存在你的设备上，退出登录即在服务端作废。

云同步

云同步默认关闭，要在账号页自己打开，只对打开它的那台设备生效。打开后，账号服务会按你的邮箱保存这些记录的原文：首页和数据库页的收藏、各栏目的自测勾选和公式题、学习路线、游乐场的最好成绩、复习卡片的进度和你自己写的卡片，以及研习台的全部会话（其中有你的回答、想法、导入的笔记和知识图）和提示词改动。这些数据只用来在你登录同一账号的设备之间同步，不给别人看，不用来训练模型，也不发给 AI 服务商。登录状态、API key、显示设置和 AI 助手的对话不同步。你可以在账号页“删除云端副本”，服务器上的同步数据会立即删除。

托管与第三方资源

网站托管在 GitHub Pages，访问时 GitHub 可能按其政策记录访问日志。部分页面会从 cdn.jsdelivr.net 加载 RDKit.js，从 PubChem 查询分子信息；这些请求由你的浏览器直接发出。“教学视频”页的封面图随网站一起发布；在页面里点了播放，才会从 YouTube（youtube-nocookie.com）或哔哩哔哩加载它们的播放器，之后适用这两个平台的隐私政策。

你的权利

你可以随时清除浏览器数据来删除本地保存的内容，在账号页删除云同步的云端副本；也可以联系我们查询、更正或删除我们因付款与 Pro 账号而持有的邮箱、订单与用量记录（法律要求保留的财务记录除外）。
