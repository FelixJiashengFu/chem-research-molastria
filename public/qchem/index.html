游戏 01 · 自由电子模型

盒中粒子调颜色

共轭链上的 π 电子可以近似看成关在一维盒子里的粒子。最高占据能级（HOMO）的电子吸收一个光子跳到最低空能级（LUMO），吸收的波长由盒子长度和电子数决定。

目标：让分子吸收和左边色块一样颜色的光（误差 8 nm 以内）。

目标吸收色？ 你的分子吸收 溶液大致呈现互补色

原理与局限

长度为 L 的一维盒子里，电子的能级是

Eₙ = n²h² / (8mₑL²)，n = 1, 2, 3, …

N 个 π 电子两两成对填满前 N/2 个能级，HOMO 是 n = N/2，LUMO 是 n = N/2 + 1，所以吸收的波长是

ΔE = (N + 1)h² / (8mₑL²)，λ = 8mₑcL² / (h(N + 1))

这是 Kuhn 等人在 1940 年代用来解释花菁类染料颜色的自由电子模型。它忽略了电子之间的相互作用、链两端的杂原子和链上的键长交替，所以只能定性地给出“链越长、吸收越红”的趋势；对键长交替明显的多烯，误差会很大。色块用的是波长到 RGB 的近似换算，屏幕上的颜色只是示意，“互补色”也只是粗略的说法。

游戏 02 · 氢原子波函数

猜轨道

下面是一个氢原子轨道在 y = 0 平面上的截面。看节点（波函数为零、颜色断开的地方）和相位（两种颜色），选出它是哪一个。

数一数：圆形节点是径向节点（n − l − 1 个），穿过原子核的节线来自角向节面（l 个）。

原理与局限

氢原子的波函数可以写成径向部分和角向部分的乘积，图里用的是实数形式的轨道（px、dxz 等是复数球谐函数的组合）：

ψₙₗₘ(r, θ, φ) = Rₙₗ(r) · Yₗₘ(θ, φ)

径向部分 Rₙₗ 有 n − l − 1 个零点，在截面上是圆形节点；角向部分有 l 个节面（或节锥），在截面上是穿过原子核的直线。例如 3pz 有一个径向节点和一个节面（xy 平面），3dz² 的节面是两个圆锥（3cos²θ = 1）。

截面只看 y = 0 这一个平面：dx²−y² 的两个节面 x = ±y 在这个平面里只剩下 z 轴一条线，所以它的截面和 px 很像，要靠相位分辨（dx²−y² 两边同号，px 两边异号）。只画了 n ≤ 3 的轨道，坐标以玻尔半径 a₀ 为单位，各题的视野大小不同。

游戏 03 · 构造原理、泡利原理、洪特规则

电子排布

点轨道格子放电子：点一次放一个，点两次成对，点三次清空。排好后检查，看是否是这个元素的基态电子排布。

从下往上能量升高（中性原子的大致顺序）。每个格子是一个轨道，最多放两个自旋相反的电子。

原理与局限

三条规则：构造原理（按能量从低到高填，顺序是 1s 2s 2p 3s 3p 4s 3d 4p，即 n + l 小的先填，相同时 n 小的先填）；泡利原理（一个轨道最多两个电子，自旋相反）；洪特规则（同一亚层里先每个轨道各放一个、自旋平行，再成对）。

前 36 号元素里有两个例外：铬是 [Ar] 3d⁵4s¹，铜是 [Ar] 3d¹⁰4s¹，这是光谱实验测得的基态。教科书常说“半满和全满的 d 亚层更稳定”，更准确的原因是 3d 和 4s 能量非常接近，交换作用和电子排斥决定了谁更低，构造原理只是一个经验顺序。这里只考虑中性原子的基态；离子（例如 Fe²⁺ 先失去 4s 电子）不在游戏里。

游戏 04 · 一维方势垒

量子隧穿闯关

经典粒子能量不够就翻不过势垒，量子粒子却有一定概率穿过去，能量够了也可能被弹回来。完成四个关卡，再自由试试。

原理与局限

粒子从左边入射，在势垒两侧和内部分别写出薛定谔方程的解，要求波函数和它的导数在两个边界连续，就能精确求出透射概率 T 和反射概率 R（T + R = 1）。能量低于势垒时：

T = [1 + V₀² sinh²(κa) / (4E(V₀ − E))]⁻¹，κ = √(2m(V₀ − E)) / ħ

能量高于势垒时 sinh 换成 sin，κ 换成 k′ = √(2m(E − V₀))/ħ；当 k′a = π, 2π, … 时 T = 1，叫共振透射。质子比电子重 1836 倍，κ 大约 43 倍，所以同样的势垒它几乎穿不过去，这也是化学里氢转移隧穿效应只在很窄的势垒上明显的原因。

这里的势垒是理想的方形，粒子是单一能量的平面波；真实分子里的势垒是平滑的，常用 WKB 近似或更完整的量子动力学处理。发射粒子是按 T 随机决定每个粒子穿过还是弹回，所以每次的数目会有起伏。

游戏 05 · Hückel 理论

芳香性判断

平面、单环、完全共轭的体系，π 电子数是 4n + 2 时是芳香的，是 4n 时是反芳香的。先数清楚 π 电子，再作答。

原理与局限

N 元环的 Hückel π 轨道能量是

Eₖ = α + 2β cos(2πk/N)，k = 0, 1, …, N − 1（β < 0）

最低的能级只有一个，往上的能级两两简并。4n + 2 个电子正好填满成对的能级，形成闭壳层，比同样数目的孤立双键更稳定（苯的离域能是 2β）；4n 个电子会让最高一对简并能级各剩一个电子，在 Hückel 理论里是不稳定的开壳层。每个碳提供一个 p 电子，正电荷少一个、负电荷多一个。

局限：真实分子不一定是平面的。环辛四烯是澡盆形，π 键不共轭，实际上是非芳香的；环丁二烯会扭成长方形，但仍然很不稳定。游戏里的题目都按“假设它是平面的”来判断，“离域能”以同样数目的孤立双键为参照，是 Hückel 近似下的数值。

游戏 06 · 里德伯公式

氢原子光谱

电子从高能级跳到低能级时放出一个光子。给你一条谱线的波长，选出起点和终点能级，看能不能发出这条线。三次以内找到算赢。

从能级（上）
跳到能级（下）

原理与局限

氢原子发出的光子波长满足里德伯公式：

1/λ = R_H (1/n₁² − 1/n₂²)，R_H = 1.0967758 × 10⁷ m⁻¹

n₁ = 1 是莱曼系（紫外），n₁ = 2 是巴耳末系（其中 4 条在可见光区），n₁ = 3 是帕邢系（红外）。R_H 已经按氢原子的约化质量修正，给出的是真空中的波长；空气中的波长短约 0.03%，所以手册里的 Hα 常写 656.28 nm，这里是 656.47 nm。精细结构、兰姆位移等更小的分裂没有考虑。

游戏 07 · 量子物理 · 自旋 ½ 的测量

Stern–Gerlach 自旋过滤

不均匀磁场把银原子束按自旋分成两束。每个分析器只放行“+”那一束。原子以 +z 自旋从左边进入，转动中间的分析器，完成三个关卡。

原理与局限

自旋 ½ 的原子处在 |+θ⟩（沿 xz 平面里 θ 方向朝上）时，沿 θ′ 方向测量得到“+”的概率是

P(+θ′ | +θ) = |⟨+θ′|+θ⟩|² = cos²((θ′ − θ)/2)

通过分析器以后，原子就处在 |+θ′⟩，忘记了原来的方向。所以 +z 和 −z 之间相差 180°，透过率 cos²(90°) = 0；中间插一个 90°（+x）的分析器，透过率变成 cos²(45°) × cos²(45°) = 1/4。把 180° 均匀分成 m + 1 步，透过率是 cos²⁽ᵐ⁺¹⁾(π/(2(m + 1)))，m 越大越接近 1，这和量子芝诺效应是同一个数学。

Stern 和 Gerlach 1922 年用银原子做了第一个实验，串联分析器的思想实验来自 Feynman 讲义和 Sakurai 的教科书。这里忽略了原子束的速度分布和磁场的不均匀程度，把每个分析器看成理想的投影测量；角度只取 xz 平面。

游戏 08 · 量子物理 · 纠缠与非定域性

CHSH 贝尔游戏

裁判随机给 Alice 一个比特 x、给 Bob 一个比特 y，两人不能通信，各回答一个比特 a、b。只有 x 和 y 都是 1 时要求答案不同，其余情况要求答案相同。先用经典策略试试，再换成纠缠光子。

事先约好：收到 0 和收到 1 时各回答什么。点按钮切换 0 / 1。

Alice 收到 0 答收到 1 答
Bob 收到 0 答收到 1 答

两人共享一对偏振纠缠的光子 |Φ⁺⟩。收到的比特决定用哪个角度去测自己的光子，测到的结果就是答案。

    原理与局限

    经典策略：每人的回答只能取决于自己收到的比特（随机策略只是确定策略的混合，不会更好）。一共 2⁴ = 16 种确定策略，逐个试会发现四道题最多答对三道，所以获胜概率不超过 75%。这就是 CHSH 不等式 |S| ≤ 2 的游戏说法，获胜概率 = 1/2 + S/8。

    量子策略：共享 |Φ⁺⟩ = (|HH⟩ + |VV⟩)/√2，两人分别沿 α、β 测偏振，结果相同的概率是

    P(a = b) = cos²(α − β)，P(赢) = ¼ [cos²(α₀ − β₀) + cos²(α₀ − β₁) + cos²(α₁ − β₀) + sin²(α₁ − β₁)]

    取 α₀ = 0°、α₁ = 45°、β₀ = 22.5°、β₁ = −22.5° 时，四项都是 cos²(22.5°)，获胜概率 cos²(π/8) ≈ 85.36%，S = 2√2。Tsirelson 在 1980 年证明这是量子力学允许的最大值。纠缠不能传递信息：每个人单独看自己的结果，0 和 1 永远各占一半。

    2015 年以来的无漏洞 Bell 实验（Hensen 等、Giustina 等、Shalm 等）同时堵住了探测效率和定域性两个漏洞。这里的“1000 轮”是按理论概率随机抽样，不是真实的光子；真实实验的可见度不到 100%，获胜率会低一些。

    游戏 09 · 量子算法 · 电路模型

    量子电路拼图

    每道题给你几种量子门，把它们排成电路，从初态做出目标量子态（整体相位不算）。下面的柱子是每个基矢的振幅，虚线框是目标。

    原理与局限

    门的矩阵（作用在一个比特上）：

    H = (1/√2)[[1, 1], [1, −1]]，X = [[0, 1], [1, 0]]，Z = [[1, 0], [0, −1]]，S = diag(1, i)，T = diag(1, e^{iπ/4})

    CNOT 在控制比特为 1 时翻转目标比特。几个常用的恒等式：HZH = X，HXH = Z，T² = S，S² = Z；H 加 CNOT 就能把两个比特纠缠起来。保真度按 |⟨目标|ψ⟩|² 计算，所以整体相位不影响对错。

    每道题的“最少门数”是用穷举搜索在允许的门里算出来的（测试里会重新搜一遍）。这是理想的、没有噪声的态矢量模拟；真实量子计算机的门有误差，而且两比特门要比单比特门慢、错误率高，所以实际编译时数的往往是 CNOT 的个数和电路深度。

    游戏 10 · 量子计算机 · 量子纠错

    纠错救援

    一个逻辑比特 |0⟩ 被编码成三个物理比特 |000⟩。每一轮，每个物理比特都可能被噪声翻转。你看不到比特本身（直接读会破坏量子信息），只能看两盏奇偶校验灯，然后决定翻转哪个比特把它救回来。

    q0 ⊕ q1q1 ⊕ q2

    原理与局限

    两盏灯测的是相邻比特的奇偶 q0 ⊕ q1 和 q1 ⊕ q2（量子线路里用一个辅助比特和两个 CNOT 测 Z₀Z₁、Z₁Z₂），它们只告诉你“哪两个比特不一样”，不告诉你逻辑比特是 0 还是 1，所以测量不会破坏叠加态。只有一个比特翻转时，四种灯的组合各对应唯一的修法：

    (灭, 灭) 不动；(亮, 灭) 翻 q0；(亮, 亮) 翻 q1；(灭, 亮) 翻 q2

    两个比特同时翻转时，灯的样子和“另一个比特单独翻转”完全一样，按最可能的情况修就会修错，变成逻辑错误。每个比特独立以概率 p 翻转时，逻辑错误率是 3p²(1 − p) + p³ = 3p² − 2p³，p < 1/2 时它比 p 小：这就是纠错有用的门槛。

    局限：这个码只防比特翻转，不防相位翻转（Z 错误）；能同时防两种错误的最小码要 5 个比特，实际硬件多用表面码。真实设备上测量本身也会出错，要重复测量多轮再解码。Google 2024 年在超导芯片上演示了表面码的逻辑错误率随码距增大而指数下降（Acharya 等，Nature 638, 920，2025 年刊出）。

    游戏 11 · 量子算法 · 振幅放大

    Grover 寻宝

    N 个盒子里只有一个宝物。经典地一个个打开，平均要开一半；Grover 算法从均匀叠加出发，每次迭代把宝物的振幅转大一点，大约 (π/4)√N 次后测量几乎必中。但转过头概率会下降，你只有一次测量机会。

    原理与局限

    一次 Grover 迭代 = oracle（把宝物的振幅变号）+ 扩散（把每个振幅绕平均值翻转）。在“宝物”和“其余均匀叠加”两个方向张成的平面里，这是一次 2θ 的转动，sin θ = 1/√N：

    k 次迭代后 P(宝物) = sin²((2k + 1)θ)，最佳 k ≈ π/(4θ) − 1/2 ≈ (π/4)√N

    N = 4 时 θ = 30°，一次迭代就转到 90°，必中。N = 1024 时最佳是 25 次，成功率约 99.95%；经典搜索平均要查 (N + 1)/2 ≈ 512 次。Bennett、Bernstein、Brassard 和 Vazirani 1997 年证明，任何量子算法都至少要查约 √N 次，所以 Grover 的平方加速是最优的。

    这里的 oracle 是现成的；实际问题里 oracle 要用可逆电路实现，开销常常抵消掉平方加速，在有纠错开销的硬件上尤其如此。模拟没有噪声。

    游戏 12 · 量子生物学 · 环境辅助的量子传输

    噪声助推能量传递

    光合作用里，激发能要在一张色素分子组成的网络里走到反应中心。完全相干的量子波动可能被能量差或相消干涉卡住；环境的噪声（退相干）太多又会把它冻住。为三张网络各找到最合适的噪声强度。

    原理与局限

    激发在 n 个位点上的密度矩阵按 Haken–Strobl 主方程演化（ħ = 1，能量和速率以耦合 J 为单位）：

    dρ/dt = −i[H, ρ] − {Λ, ρ} − γ(ρ − diag ρ)，Λ = (κ/2)|trap⟩⟨trap| + (Γ/2)·1

    κ = 1 是反应中心取走激发的速率，Γ = 0.02 是激发在每个位点上衰减掉的速率，γ 只破坏位点之间的相位。效率 η = κ∫ρ_trap dt，用 ∫e^{𝓛t}dt = −𝓛⁻¹ 直接解线性方程得到，没有时间步长误差。三张网络：整齐的链在 γ = 0 时最好，噪声只会拖慢；能量台阶（0、3、6 J）要靠噪声展宽能级才能跨过去，最佳 γ 和台阶高度同一量级；菱形网络的两条路耦合符号相反，相干时从起点出发的波在终点相消，激发被锁在“暗态”里，噪声把干涉打破。

    这就是 Mohseni 等（2008）、Plenio 与 Huelga（2008）、Rebentrost 等（2009）提出的“环境辅助的量子传输”。它是模型上的结论；真实 FMO 复合物里的长寿命振荡后来被认为主要来自振动，生理条件下电子相干对效率有多大贡献仍有争议。这里的网络是玩具模型，不是 FMO 的真实参数；用真实参数的演示在量子嘉年华 · 量子生物学。

    游戏 13 · 物理疆界 · 量纲分析

    普朗克单位工坊

    1899 年普朗克发现，只用自然界的几个常数就能定出一套与人无关的单位。调 ħ、c、G 三个指数，让 ħᵃ cᵇ Gᶜ 的量纲和目标一样。

    原理与局限

    三个常数的量纲：ħ = [M L² T⁻¹]，c = [L T⁻¹]，G = [M⁻¹ L³ T⁻²]。ħᵃ cᵇ Gᶜ 的量纲是

    M^(a − c) · L^(2a + b + 3c) · T^(−a − b − 2c)

    这个 3 × 3 方程组的行列式是 2，不为零，所以每个目标量纲都有唯一一组指数，而且一定是整数或半整数。例如普朗克长度 ℓ_P = √(ħG/c³) ≈ 1.616 × 10⁻³⁵ m，普朗克质量 √(ħc/G) ≈ 2.176 × 10⁻⁸ kg。力 c⁴/G 和功率 c⁵/G 里根本没有 ħ，是纯经典的组合。

    量纲分析只能定出“量级”，定不出前面的纯数因子，所以“普朗克长度上时空会变得量子化”只是一个量级估计，不是已知的物理定律。数值用 CODATA 2018 的常数，温度单位还需要玻尔兹曼常数，这里没有包括。

    游戏 14 · 物理疆界 · Bronstein 立方体

    ħ-c-G 立方体分拣

    把 1/c、G、ħ 看成三个开关：关掉 1/c 表示光速当作无穷大，关掉 G 表示忽略引力，关掉 ħ 表示忽略量子。每个现象至少要打开哪几个开关才解释得了？选好后看它落在立方体的哪个角。

    原理与局限

    这个立方体最早来自 Bronstein 1930 年代的讨论，后来由 Zelmanov、Okun 等人整理成“cGh 立方体”。原点是牛顿力学，三条棱的另一端是狭义相对论（1/c）、牛顿引力（G）和量子力学（ħ）；三个面对角是广义相对论（1/c、G）、量子场论（1/c、ħ）和牛顿量子引力（G、ħ）；最远的角三者全开，是还没有建立的量子引力。

    “打开”看的是要解释的那个结果里是否非出现这个常数不可。所以有的题会出乎意料：白矮星的钱德拉塞卡极限 M_Ch ∝ (ħc/G)^{3/2} / m_H² 三个常数都用到了，但它不需要量子引力，只需要相对论性的简并电子加上引力；霍金辐射也是在弯曲时空上做量子场论的半经典结果。开关的划分是粗粒度的教学工具，不是严格的分类：同一个现象往往还用到 e、k_B 等其他常数。
