METHOD & LIMITS

    
方法：三级精度、六条可靠性规则

    
目标是找到同时强抗氧化、强抗还原、与 Li⁺ 结合强度适中的溶剂分子。评估分三级，每升一级更准、更贵、覆盖的分子更少；排名用多目标 Pareto 前沿，不压缩成单一分数。

    

      
层级对象计算内容方法（均在 Rowan 上）

      
        
Tier 1 · 筛选每轮全部分子构象搜索 → 中性 / 阳离子 / 阴离子 / Li⁺ 络合物优化 → IP、EA、Li⁺ 结合能UMA-S 1.2（uma_s_1_2_omol），再在同一几何上做 UMA-M 单点检查分歧

        
Tier 2 · 电位每轮前 3–5 个乙腈中的单电子氧化 / 还原电位（V）氧化还原电位工作流，Rapid 模式（GFN2-xTB 几何 + r²SCAN-3c 单点）

        
Tier 3 · 验证每轮 2–3 个“有希望但可疑”的中性与离子态的高精度单点，得到 DFT 级 IP、EAωB97M-V/def2-TZVPD（与 OMol25 同一约定），或电位工作流的 Meticulous 模式

      
    

    

      
性质Tier 1 算法（UMA）Tier 2目标方向

      
        
抗氧化绝热 IP = E(阳离子, +1, 二重态) − E(中性, 0, 单重态)氧化电位越高越好

        
抗还原绝热 EA = E(中性) − E(阴离子, −1, 二重态)还原电位溶剂：还原电位越负越好；SEI 添加剂相反

        
溶剂化Li⁺ 结合能 = E(Li⁺·溶剂, +1) − E(Li⁺) − E(溶剂)—落在参考溶剂范围内：太强难脱溶剂，太弱溶盐差

        
抗夺氢（可选）—键解离能工作流最弱 C–H 键越强越好

UMA-S 的主族还原电位误差与低成本 DFT 方法 B97-3c（0.260 V）相当；UMA-M 与 eSEN-S 存在离群值，使 RMSE 超过 1 V——这正是“S/M 模型分歧即存疑”这条规则的依据。另一项独立基准发现这类模型在纯电子转移与训练集中少见的活泼离子上会退化，建议“势函数几何 + DFT 单点 + 隐式溶剂校正”，与这里的分级设计一致。

      

    

    

      

        
种子、参考集与分子约束

        
种子与参考集为 9 个常用溶剂：EC、PC、DMC、DEC、EMC、FEC、VC、DME、DOL。参考值优先取自 LIBE 数据集（ωB97X-V/def2-TZVPPD/SMD，以碳酸酯为主），缺失的由 Tier 3 补齐。进入计算前由 RDKit 自动检查：只含 C、H、O、F（可放宽到 N、S、P、B）；重原子不超过 20 个；SMILES 能解析；合成可及性低于阈值；排除过氧、叠氮等不稳定或危险基团；按 InChIKey 去重，不重复评估。

        
新颖性检查按 InChIKey 查询 PubChem。未收录只说明“新”，不说明“好”或“可合成”。

      

      

        
已知局限

        
    
          
  • 电位工作流的溶剂固定为乙腈，不是碳酸酯电解液，只适合做相对排序。
    • 
          
  • 忽略阴离子（如 PF₆⁻）与电极界面对氧化稳定性的影响。
    • 
          
  • 不考虑黏度、熔点、闪点、电导率等宏观性质。
    • 
          
  • 合成可及性只是启发式分数，没有实验验证；结论只作为初筛。
    • 
          
  • SCE 到 Li/Li⁺ 的换算默认用水相约定（SCE = +0.241 V，Li⁺/Li = −3.040 V，均相对 SHE），在乙腈体系里需要核对后写入说明。
