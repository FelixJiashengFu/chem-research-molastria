TRAIN YOUR OWN CHEMISTRY AGENT

用开源小模型，
训练你自己的化学研究 Agent。

一个 2–9B 的小模型，学会调用 RDKit、PubChem 和计算平台这些工具，再用可验证的化学规则做强化学习，就能在一张消费级显卡甚至笔记本上运行，数据不出本机。这份指南给出选型、数据构造、LoRA 微调、GRPO 强化学习、评测和部署的完整步骤，代码可以直接复制。

更新于 2026-10-28模型信息核对自 Hugging Face 官方模型卡所有链接已逐一检查

00路线总览

先让大模型（老师）带着工具把任务做对，把做对的过程记下来，教给小模型；再用程序能自动判分的化学任务做强化学习；最后在本机部署，接入 MolAstria 的 AI 助手和 AI 实验室。

  1. 定任务与工具写清要回答的问题和要调用的工具：RDKit、PubChem、Rowan、文献检索
  2. 选底座模型按显存与许可证挑 2–9B 的小模型
  3. 造数据老师模型生成工具调用轨迹，RDKit 校验，只留做对的
  4. LoRA 微调单卡几小时，让小模型学会格式与工具
  5. 强化学习GRPO + 可验证奖励：结构合法、约束满足
  6. 评测与部署ChemBench 与自建测试集；vLLM / Ollama 本地服务

只想先体验：装好 Ollama 后运行 ollama run qwen3.5:4b，再按第 5 步把它接入本站的 AI 助手，不需要训练就能用本地模型问目录、提候选分子。

01按你的显存选模型

选择显存和要做的事，下方表格会标出放得下的模型。显存是按参数量粗略估算的（4-bit 推理约 0.6 GB/十亿参数 + 1.5 GB；QLoRA 微调约 1 GB/十亿参数 + 4 GB；GRPO 约为微调的 1.6 倍），实际还取决于序列长度和批大小。

03低显存 MoE：总参数大，每次只激活一小部分

07第 1 步：造数据——老师带工具做题，只留做对的

写一份任务清单（tasks.txt，每行一个问题，例如“给出 3 个含两个 F、不超过 12 个重原子的碳酸酯溶剂并核对分子式”），让老师模型在真实工具环境里作答，把完整的对话和工具调用记下来。只保留能被程序验证为正确的轨迹（拒绝采样），这样小模型学到的是“正确地用工具”，而不是老师的幻觉。

make_traces.py
# pip install openai rdkit
# Generate tool-use trajectories with a teacher model and keep only the ones RDKit can verify.
import json, os
from openai import OpenAI
from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

teacher = OpenAI(base_url="https://api.deepseek.com", api_key=os.environ["DEEPSEEK_API_KEY"])
TOOLS = [{
    "type": "function",
    "function": {
        "name": "describe_molecule",
        "description": "Validate a SMILES string and return its canonical form, formula, weight and heavy-atom count.",
        "parameters": {"type": "object", "properties": {"smiles": {"type": "string"}}, "required": ["smiles"]},
    },
}]

def describe_molecule(smiles: str) -> dict:
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return {"valid": False}
    return {"valid": True, "canonical": Chem.MolToSmiles(mol), "formula": rdMolDescriptors.CalcMolFormula(mol),
            "mw": round(Descriptors.MolWt(mol), 2), "heavy_atoms": mol.GetNumHeavyAtoms()}

def run(task: str, max_steps: int = 6) -> list[dict]:
    messages = [{"role": "system", "content": "You are a careful chemist. Check every structure with the tool before answering."},
                {"role": "user", "content": task}]
    for _ in range(max_steps):
        msg = teacher.chat.completions.create(model="deepseek-flash", messages=messages, tools=TOOLS).choices[0].message
        turn = msg.model_dump(exclude_none=True)
        turn.pop("reasoning_content", None)          # keep the visible answer and tool calls only
        messages.append(turn)
        if not msg.tool_calls:
            return messages
        for call in msg.tool_calls:
            result = describe_molecule(**json.loads(call.function.arguments))
            messages.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(result)})
    return messages

def verified(messages: list[dict]) -> bool:
    # Keep a trace only if the tool was used, every structure it saw was valid, and the run ended with an answer.
    results = [json.loads(m["content"]) for m in messages if m["role"] == "tool"]
    return bool(results) and all(r["valid"] for r in results) and messages[-1]["role"] == "assistant"

with open("traces.jsonl", "w", encoding="utf-8") as out:
    for task in open("tasks.txt", encoding="utf-8"):
        trace = run(task.strip())
        if verified(trace):
            out.write(json.dumps({"messages": trace, "tools": TOOLS}, ensure_ascii=False) + "\n")

数据从哪来

  • 自己组里的真实问题：组会记录、常被问的计算设置、合成路线讨论。
  • 公开指令数据：SMolInstruct、Mol-Instructions（CC-BY-4.0）。
  • 可自动判分的任务：ether0-benchmark 的题型很适合改写成强化学习任务。
  • 本站 AI 实验室导出的候选与计算结果（CSV / JSON），可以直接变成“提出 → 校验 → 解释”的训练样本。

经验

  • 500–2,000 条高质量轨迹就能让小模型学会工具格式；质量比数量重要。
  • 按 InChIKey 给分子去重，并把同一分子只放进训练集或测试集之一，避免泄漏。
  • 保留一部分“工具报错、模型改正”的轨迹，小模型才学得会纠错。

09第 3 步：强化学习——用化学规则当裁判

GRPO（DeepSeekMath 提出）让模型对同一题生成多个答案，按奖励比较优劣，不需要单独的奖励模型。化学特别适合这种“可验证奖励”：结构合不合法、元素和大小是否满足约束、性质是否落在目标范围，都能用 RDKit 或计算平台自动判断。ether0 就是这样训练出来的。

train_grpo.py
# pip install "trl>=0.20" rdkit datasets
# GRPO with a verifiable chemistry reward: RDKit grades every answer, no reward model needed.
import re
from datasets import Dataset
from rdkit import Chem, RDLogger
from trl import GRPOConfig, GRPOTrainer

RDLogger.DisableLog("rdApp.*")
ALLOWED = {"C", "H", "O", "F"}
TASK = ("Propose one lithium-battery electrolyte solvent containing only C, H, O and F, "
        "with at most 12 heavy atoms and at least two fluorine atoms. Answer as ....")
prompts = Dataset.from_list([{"prompt": [{"role": "user", "content": TASK}]}] * 256)   # use many varied tasks in practice

def text_of(completion):
    return completion[-1]["content"] if isinstance(completion, list) else completion

def chemistry_reward(completions, **kwargs):
    rewards = []
    for completion in completions:
        found = re.search(r"(.*?)", text_of(completion), re.S)
        mol = Chem.MolFromSmiles(found.group(1).strip()) if found else None
        if mol is None:
            rewards.append(-1.0)                      # no answer or an invalid structure
            continue
        symbols = [a.GetSymbol() for a in mol.GetAtoms()]
        score = 0.2                                   # a valid structure
        score += 0.4 if set(symbols) <= ALLOWED else -0.4
        score += 0.2 if mol.GetNumHeavyAtoms() <= 12 else -0.2
        score += 0.2 if symbols.count("F") >= 2 else 0.0
        rewards.append(score)
    return rewards

trainer = GRPOTrainer(
    model="chem-agent-merged",                        # start from the SFT model
    reward_funcs=chemistry_reward,
    train_dataset=prompts,
    args=GRPOConfig(output_dir="chem-agent-grpo", num_generations=8, max_completion_length=512,
                    per_device_train_batch_size=8, gradient_accumulation_steps=4,
                    learning_rate=5e-6, bf16=True, logging_steps=5),
)
trainer.train()
trainer.save_model("chem-agent-grpo")

好奖励的样子

  • 能自动、确定地算出来：RDKit 解析、元素与原子数、官能团 SMARTS、分子量、相似度。
  • 分层给分：先奖励“结构合法”，再奖励“满足约束”，最后奖励“性质达标”。
  • 贵的打分（UMA、DFT）只用在少量样本上，或先离线算好再查表。

多卡与大规模

  • verl：多卡、多节点的强化学习框架，支持多轮工具调用的 Agent RL。
  • TRL GRPO 文档：奖励函数、vLLM 加速生成等参数说明。
  • Unsloth：单卡 GRPO 更省显存。

10第 4 步：评测——训练前后都要量

  • 通用化学能力：ChemBench（代码、数据），确认微调没有让基础化学知识退化。
  • 你的任务：留出 10–20% 自建任务做测试，统计 SMILES 合法率、约束满足率、工具调用成功率、最终答案正确率。
  • 对比三个版本：原始底座、SFT 后、GRPO 后，同一测试集、同一采样参数。
  • 人工抽查：每轮随机看 30 条完整轨迹，找出“答对了但理由错”的情况。

from mcp.server.fastmcp import FastMCP
from rdkit import Chem
from rdkit.Chem import Descriptors, rdMolDescriptors

mcp = FastMCP("chem-tools")

@mcp.tool()
def describe_molecule(smiles: str) -> dict:
    """Validate a SMILES string and return canonical SMILES, formula, weight and heavy-atom count."""
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return {"valid": False}
    return {"valid": True, "canonical": Chem.MolToSmiles(mol), "formula": rdMolDescriptors.CalcMolFormula(mol),
            "mw": round(Descriptors.MolWt(mol), 2), "heavy_atoms": mol.GetNumHeavyAtoms()}

if __name__ == "__main__":
    mcp.run()

13常见坑

结果可信度

  • 小模型会编造 SMILES、CAS 号和文献；所有结构一律过 RDKit，所有数据一律回到数据库核对。
  • 不要让模型直接给数值性质（沸点、电位）当结论；数值来自计算或数据库，模型负责调度和解释。
  • 训练集和测试集按分子去重，否则分数虚高。

许可证与安全

  • 商用优先 Apache-2.0 / MIT；LFM（LFM Open License）、ChemDFM（AGPL-3.0）、TxGemma（HAI-DEF）、Nemotron（OpenMDW）都要先读条款。
  • 微调可能削弱底座原有的安全行为；涉及危险物质合成的请求要在工具层拦截。
  • API 老师的服务条款可能限制用输出训练模型，使用前确认。
