第一次打开

Windows：安装包暂未做代码签名，Windows 可能提示“Windows 已保护你的电脑”。点 更多信息 → 仍要运行 即可。应用会装在当前用户目录，不需要管理员权限；Windows 11 已自带所需的 WebView2，Windows 10 若缺少会自动下载。

macOS：应用暂未经过 Apple 公证。打开 .dmg，把 MolAstria 拖进“应用程序”；第一次打开若提示无法验证开发者，到 系统设置 → 隐私与安全性，在页面下方点 仍要打开。

桌面版能做什么

  • 离线浏览目录、讲解和训练指南；AI 实验室的 RDKit 与 AI 调用需要联网。
  • AI 助手设置里选“其他兼容接口”，填 http://localhost:11434/v1（Ollama）或 http://localhost:8000/v1（vLLM）即可使用本机模型。
  • 收藏、偏好和实验室项目保存在本机，和浏览器里的数据互不影响；可以用“导出项目”在两边迁移。

从源码构建

桌面版用 Tauri 打包，源码在仓库的 desktop/ 目录。每次发布由 GitHub Actions 在 Windows 与 macOS 机器上自动构建，构建日志公开可查。
