13QUESTIONS
这本册子没说出口的话

地图会过期，边界要自己核

What a directory cannot tell you — licenses, fields, and theory levels.

可被追问的五点

  • 链接核验只对当天负责。原册标了核验日期，这是诚实，也是提醒：端点会迁、会挂（OQMD 本次实测 502）。把导航条目写进代码前，必须逐个复测，而不是引用册子的日期。
  • “免费”不等于“可批量”。网页免费、API 收费/限流、禁止再分发是三回事。KEGG 的程序化访问、CAS/ICSD 的订阅边界、谱图库的再分发限制，都不在“一句话定位”里，自动化前逐条读条款。
  • 同协议不同字段。OPTIMADE 统一了查询语法，没统一各家的字段完备度：COD 要点名才给坐标，NOMAD 的 dimension_types 不可检索。统一入口的工程量，恰恰在这些差异里。
  • 结构有“维度”之别。ChEMBL 的 molfile 是 2D 重原子坐标，PubChem 给 3D 全原子，COD 给实验晶胞——三者都能画成“结构图”，但只有后两类能直接进构象/周期计算。拿 2D 坐标当 3D 用，是最常见的静默错误。
  • 数据能混吗，册子回答不了。不同库的形成能来自不同泛函与校正方案（如 MP 的 MP2020 校正），混进同一个训练集就是污染。本机的导出层用理论级别键（方法+基组/截断+赝势+色散+自旋+程序+能量类型）硬拦截，这条纪律不在导航册的职责内，但用导航的人必须自己补上。

复现清单（本机接入部分）

  1. 在 WSL2 里进入 chemdb-agent，运行 uv run --python 3.11 python -m pytest tests/ -q，应得 58 passed（录制回放，不依赖实时网络）。
  2. 查端点存活：对 AFLOW、COD、NOMAD、JARVIS、Materials Cloud 的 /v1/info 各发一次 GET，应为 200；OQMD 当前应为 502（与本册记录对照）。
  3. 验资源目录：调用目录模块的 search_resources(integration="optimade")，应恰好返回 5 条；总数应为 103。
  4. 验 ChEMBL：以 aspirin 按名称检索，第一条应为 CHEMBL25、13 个重原子、电荷 0；偶发 EBI 500 时适配器会自动退避重试。
主张与证据强度

原册的主张是“分层找数据”——证据是 103 条的分类与访问标签，属目录学证据，强度取决于核验的新鲜度。本讲解版新增的主张是“其中九条可被程序稳定调用”——证据是 58 个回放测试与端点实测，强于目录登记，但只对 2026-10-27 的端点状态负责。
