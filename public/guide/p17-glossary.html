术语表与关键数字

Glossary, key numbers, and where to read next.
OPTIMADE
材料数据库的统一 REST 协议：同一套过滤语法（如 elements HAS ALL "Si"）查多家库。本机五家材料库经它接入。
理论级别
一组计算的“配方”：方法、基组或截断能+赝势、色散校正、自旋处理、程序与版本。配方不同，能量不可直接比较或混训。
形成能
化合物相对其组成元素单质的能量，每原子归一（eV/atom）。MP 的形成能带 MP2020 兼容性校正，与原始总能量分开标注。
基组 / ECP
基组是波函数的展开基；ECP（有效核势）把重元素内层电子换成势。BSE（017）可编程取两者文本，重元素自动带 ECP。
QSAR
定量构效关系：用描述符从结构预测活性。ChEMBL 的人工标定活性数据是其金标准来源。
pLDDT
AlphaFold 的逐残基置信度（0–100）。低置信区是预测的无序区，不能当实验结构使用。
CC BY-SA
知识共享“署名—相同方式共享”许可（ChEMBL 数据为 CC BY-SA 3.0）：可用可改，但衍生作品须同许可发布，与 CC-BY 不可混为一谈。

  • Materials Project 文档与 mp-api：docs.materialsproject.org —— 形成能与 MP2020 校正的口径。
  • ChEMBL API 文档：www.ebi.ac.uk/chembl/api —— 过滤语法（如 pref_name__iexact）与许可说明。
