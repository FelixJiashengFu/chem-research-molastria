先说结论：这是一张分层地图，不是一份排行榜

查一个化合物要过四道门，
这本册子把每道门的门牌号都标好了

A layered map of where chemical data lives — and which layer answers which question.

原册开篇有一句容易滑过去的话：“数据本身并不稀缺，稀缺的是知道去哪一层找。”这正是全册的骨架：103 条资源按工种分成 11 类——从综合门户、量子基准、材料与生物结构，一路到软件与社区。本讲解版不按原文顺序复述，而是先给分层逻辑，再逐类点评每一家的适用面与坑，最后附本机工程的接入实测：导航册这次不只被讲解，还被真的接进了代码。

一句话总结

遇到任何“查数据”的问题，先定层再选库：定身份去综合类（01），定结构去材料/生物类（03/04），定“算得准不准”去基准类（02/09），定活性去药物类（05）；程序化访问优先 OPTIMADE 与开放 API，订阅库只做人工核对，不进自动化管线。

三分钟速览

  • 规模：103 条、11 类、15 页；每条带一句话定位、链接与访问标签（免费/注册/学术免费/机构订阅/商业），核验日期 2026-10-27。
  • 重心：材料与晶体（03 类，15 条）与软件平台（10 类，20 条）合计占三分之一——这本册子写给“要动手算”的人，不是文献检索手册。
  • 隐含立场：免费与开放 API 的条目排布密度最高；订阅库（CAS、ICSD、CSD）被如实标价签，不假装可及。
  • 与本机的关系：讲解期间，册中 9 条已被真实接入 chemdb-agent：PubChem、Materials Project、Basis Set Exchange、ChEMBL 四个适配器，加 AFLOW、COD、NOMAD、JARVIS、Materials Cloud 五家 OPTIMADE。
  • 实测纠偏：OQMD 的 OPTIMADE 端点当前 502；Materials Cloud 要查其 MC3D 子库而非本体；NOMAD 检索须带周期性过滤——这些都不在原册里，是接入时踩出来的。
怎么读这本讲解版

赶时间：只读本页 + 全景页 + 接入实况页。选库时：按问题定类，翻到对应分类页看表末的“讲解”。做工程：直接看最后三页（接入实况、细读质疑、附录），里面有端点实测状态与复现清单。
