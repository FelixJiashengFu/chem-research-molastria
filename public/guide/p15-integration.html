哪些已经能被程序调用，
哪些只是地图上的一个名字

What is actually wired into chemdb-agent — verified endpoints, not intentions.

讲解这本导航册的同一天，册中资源被接进了本仓库的 MCP 服务器 chemdb-agent。原则只有一条：接入状态必须实测——端点通、字段对、测试过，才标“已接入”；其余 94 条只进资源目录（可检索、可查许可与访问方式），不冒充数据源。

编号资源接入方式实测要点（2026-10-27）
001PubChem适配器3D 构象优先、电荷取自性质查询；限速 0.3 s/次
017Basis Set Exchange适配器（离线）def2-SVP/TZVP 取基组文本，Pt 带 ECP；ORCA 输出用元素全名
020Materials Project适配器形成能 + MP2020 校正标注；需 API key
043ChEMBL适配器（本次新增）名称/SMILES/InChIKey 精确检索；molfile 为 2D 重原子，电荷解析 M CHG 行；5xx 退避重试
022AFLOWOPTIMADE空页时客户端会误报 infinite loop，已按错误类型区分
029CODOPTIMADE必须点名 response_fields 才返回坐标
023NOMADOPTIMADE（本次新增）Si 检索 38395 条含团簇；加 nperiodic_dimensions>=1 后 25384 条周期结构
024JARVISOPTIMADE（本次新增）端点 /optimade/jarvisdft，API 1.1 字段兼容
025Materials CloudOPTIMADE（本次新增）本体是索引元数据库；结构查 MC3D-PBE-v1 子库
如实登记的未接入

OQMD（021）：OPTIMADE 端点实测 502，目录里标 catalog，待恢复后接入。QCArchive（076）：适配器为下一阶段占位（stub）。其余条目（含全部软件与社区类）只进目录：MCP 工具 search_resources 可按关键词/类别/接入状态检索这 103 条，但不会假装能从中取结构。

讲解

这一页是本讲解版与普通书评的分界线：导航的价值最终要落在“能不能被调用”上。九条接入覆盖了四种形态——REST 适配器（PubChem/ChEMBL）、专业 API（MP）、离线数据（BSE）、统一协议（OPTIMADE 五家）。下一次扩容的优先级也由此排出：先 QCArchive 补“带能量的分子数据”，再视 OQMD 端点恢复情况补材料覆盖。
