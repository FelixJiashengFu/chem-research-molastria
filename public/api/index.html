    给 AI 和程序

    llms.txt
    给大模型看的站点说明，告诉它数据在哪、怎么署名。
    openapi.json
    OpenAPI 3.1 描述，字段结构是从数据本身推出来的，可以直接导入支持 OpenAPI 的智能体平台和代码生成器。
    molastria.mjs
    零依赖的 JS 库，浏览器、Deno、Node 18 以上都能用，带中英互通的搜索。
    chemdb-agent
    MolAstria 的 MCP 服务器，装在自己电脑上，让 Claude 等客户端直接检索晶体、分子和量子化学数据。它随包带着同一份资源目录，离线也能查。

    约定

    • 格式： 每个文件开头有三个字段： schema（现在是 1.0）、 updated（这份数据的核对日期）和 count（条数）。条目放在数组 items 里，双语文字写成 { "zh": …, "en": … }
    • 版本： v1 只会加字段，不会删字段或改含义；要改就出 v2，v1 继续保留。
    • 更新： 数据随网站一起发布，核对过才改日期。文件会被浏览器和 CDN 缓存约 10 分钟。
    • 用量： 没有次数限制。文件不大，建议在自己这边缓存一天，不要每次请求都来取。
    • 不保证： 这是个人运营的免费服务，尽力保持可用，但没有可用性承诺。链接和价格会过时，每个数据集都带核对日期，重要的事请到原始出处再核一次。

    还没有开放的

    在线模型计算（UMA、MACE、ANI-2x 等）现在只能在 模型页 里用，还没有给程序调用的 key；网状查询的实体与关系也还没有放进接口。下一步先做哪个，看大家想用哪个。想用其中一个，或者接口缺了什么字段，请告诉我们： GitHub Issues
